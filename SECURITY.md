# Security

## Reporting a vulnerability

Do not publish vulnerability details in a public issue or pull request.

Use **Security → Report a vulnerability** in the affected repository. For the Nelcota backend and SDKs, use [private vulnerability reporting](https://github.com/Nelcota/Nelcota/security/advisories/new).

Include the affected version or commit, a minimal reproduction, the security impact, and any proposed mitigation. Share only information needed to reproduce the issue; remove unrelated credentials and personal data.

If the affected repository has its own security policy, follow that policy.

## Supported versions

For the Nelcota backend and SDKs, follow the [product security policy](https://github.com/Nelcota/Nelcota/blob/main/SECURITY.md). Other repositories define their supported versions in their own README or security policy.
