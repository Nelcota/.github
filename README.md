# Nelcota community configuration

This repository contains the [Nelcota organization profile](https://github.com/Nelcota) and shared contribution defaults.

- `profile/README.md`: public organization introduction.
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, and `CODE_OF_CONDUCT.md`: default community guidance.
- `.github/ISSUE_TEMPLATE/`: bug and feature request forms.
- `.github/pull_request_template.md`: pull request checklist.

Repositories can provide their own community files to override these defaults.

The backend, SDKs, and product documentation are in [Nelcota/Nelcota](https://github.com/Nelcota/Nelcota).
