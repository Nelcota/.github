Search the documentation and existing issues before opening a new request. Include the component, version, relevant environment, and a minimal reproduction. Redact secrets and personal data from logs.

For a problem in another Nelcota repository, use that repository's issue tracker and support instructions.

Report vulnerabilities privately following [SECURITY.md](SECURITY.md).
